## Schema details to map

- Indexes and unique indexes: `server/db/schema.ts` declares 28 indexes, including composite project indexes. `spans` has unique `(project_id, trace_id, span_id)`; DuckDB must retain this identity. `logs` has no current unique identity; add the deterministic identity required by `telemetry-retention`.
- Foreign keys: 29 `.references()` calls and one table-level `foreignKey()` call appear in the schema. Preserve `cascade` and `set null` actions. `message_connections.subscription_id` is self-referential. `mock_apis.authorization_template_id` uses a table-level foreign key.
- JSON columns: `services.health_check_custom_headers`, `mock_apis.custom_headers`, `mock_apis.path_parameters`, `mock_apis.request_json`, `message_destinations.connection`, `header_templates.headers`, `authorization_templates.config`, `runs.response_headers`, `mock_api_call_history.request_body`, `spans.attributes`, `logs.attributes`. Encode/decode on SQLite text columns and DuckDB telemetry columns without changing API types.
- Date/time columns: `created_at` and `updated_at` across configuration tables; `otel_access_tokens.expires_at`; `runs.started_at`, `finished_at`, `last_telemetry_at`; `mock_api_call_history.triggered_at`; `spans.start_time`, `end_time`, `received_at`; `logs.timestamp`, `received_at`. Use one UTC representation and preserve `Date` behavior at repository boundaries.
- MySQL enums: `graph_node_positions.node_type`, `message_destinations.broker`, `message_connections.type`, `authorization_templates.type`, `runs.status`, `mock_api_call_history.status`. Map to constrained SQLite text.
- MySQL boolean columns: `projects.nodes_locked`, `services.grpc_tls`, `services.active`, `mock_apis.active`. Map to SQLite integers with application booleans.
- MySQL-specific calls: `onDuplicateKeyUpdate` in `server/utils/project.ts`, `server/repositories/canvas/index.ts`, and `server/repositories/telemetry/index.ts`; `affectedRows` in access-token, service, mock-API, and run repositories. Replace these with SQLite equivalents. `MySql2Database` appears in `server/db/index.ts` and six repository modules. No raw SQL call appears in active server code.
- Import-only fields: omit `services.code_key`, `service_endpoints.code_key`, `message_destinations.code_key`, and `mock_apis.import_method`, `import_url`, `match_url` from fresh SQLite schema. Do not port removed Graph as Code repository.

The table ownership list matches every `mysqlTable` declaration in `server/db/schema.ts` (14 SQLite, 2 DuckDB). Repository caller list comes from all active `from`, `insert`, `update`, and `delete` uses under `server/`.
